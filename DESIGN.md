## Problem Statement

Code has CI/CD. Physical work does not. Factories, labs, warehouses, hospitals,
and construction sites have written procedures — SOPs, manuals, checklists, safety
rules, incident reports — but those documents are disconnected from what actually
happens on the floor.

Workers skip steps. Use the wrong part. Miss safety checks. Repeat mistakes from
old incidents. The company technically "knows" the right process, but no runtime
checks whether reality followed it.

**Now the same primitive runs against AI agents.** That is the second story —
and it's the hackathon theme: "Build the Future of AI Agents."

Reference data: Siemens 2024 estimates the world's 500 largest companies lose
~$1.4T/year to unplanned downtime (~11% of revenue). OSHA estimates lockout/tagout
compliance prevents ~120 fatalities and ~50,000 injuries per year.

---

## What Makes This Cool

**The inversion:** most camera systems detect what happened. RealityCI verifies
whether what happened matched the procedure. That's a compiler, not a sensor.

**The generalization:** the same verifier that watches a human pack a box can
watch a Claude agent call a sequence of tools. Procedure verification is substrate-
agnostic. Physical workers today. AI agents tomorrow.

**The research confirms this pattern wins:** Google Cloud's SurgAgent (Gemini
2.0-flash-exp, zero training data, 98% accuracy on surgical instruments) shows
VLM-based procedure verification is production-ready. Winning hackathon teams
use multi-agent orchestration, domain-specific grounding, and live dashboards.
RealityCI hits all three.

## Architecture

```
Camera (live)    Production video    Watched folder      Agent trace
     │                  │            incidents.json     (scripted events)
     ▼                  ▼                  │                  │
YOLOv8n + Gemini 2.0 Flash → step detection + agent detection
     │
     ▼
Verifier (state machine)
checks current step vs. expected graph node
     │                         │
     ▼                         ▼
Nia knowledge layer      Convex (real-time state)
SOPs, manuals,                 │
incident logs                  ▼
                      Next.js dashboard (Vercel)
                      React Flow node graph
                      Citation card
                      Agent trace pane
```

The verifier receives events from **three sources** — YOLO+Gemini, production
footage playback, and the agent trace event feed. It does not know which source
emitted each event. Same state machine, same citations, same citation lookup.

## The 4-Beat Demo (180-second pitch)

**Beat 1 — Live tabletop, correct path (0-35s):**
"Code has CI/CD. Physical work doesn't. We built it."
Show the test graph (React Flow, 5 gray nodes). Demoer correctly packs the box
through step 3. Each node turns green live. Citation card shows which rule just
passed, with source PDF visible. Judges see Convex propagate in real time.

**Beat 2 — Live tabletop, failure path (35-80s):**
Demoer applies shipping label before sealing the box. UI flashes red. Node turns
red. Citation card: "Shipping SOP §2.3, page 2 — verbatim." Prior incident card:
"Pattern matches incident #23, Oct 12 — $1,200 in damaged-in-transit returns."
Demo ops generates the incident report.

**Beat 3 — Live ingest (80-120s):**
"The company's procedures don't stay static." Demo ops drops a new incident JSON
into the watched folder via hotkey. Spinner: "Nia ingesting..." Graph adds a new
check node within 10 seconds. Dashboard updates without reload. The test graph
adapted in real time. This is the wow beat.

**Beat 4 — Agent trace (120-160s):**
"Same primitive. Different actor." Switch to the agent trace pane. A scripted
Claude-style agent runs through the shipping procedure — `pick_up_box()`,
`add_product()`, `apply_label()`. Step 3 (`add_packing_material`) is deliberately
skipped; `apply_label` fires out-of-order where step 3 was expected. The verifier
catches it — same out-of-order trigger as the human demo. Same red flash. Same
Nia citation. "Today: factories. Tomorrow: every AI agent that touches the physical
world."

**Outro (160-180s):**
Cite Siemens $1.4T downtime + OSHA 120-fatalities-prevented. Hand off to Q&A.

**Timing note:** 4 beats in 3 minutes is tight. Beats 1 and 2 run as one
continuous sequence (correct pass + skipped step = ~45 seconds rehearsed). Beat 3
narration overlaps with beat 2's citation still visible on screen.

**Contingency if running long:** Beat 3 has a pre-staged hotkey fallback that
takes 3 seconds instead of 10 seconds — use it (saves ~7s, invisible to judges).
Do NOT cut Beat 4 (agent trace) — it's the on-theme beat. If still long, trim
the outro to 10 seconds.

The 5-step shipping SOP:
1. Place cardboard box on table
2. Add product (book, mug, or small object)
3. Add packing material (crumpled paper, bubble wrap, or tissue)
4. Apply packing tape across the seal
5. Apply shipping label / sticker on the top face

## Tech Stack

**CV detection:** YOLOv8n (nano) finetuned on 5 objects: cardboard box, packing
paper, packing tape, shipping label, small product item. ~8 hours of labeling +
training across Day 1 evening and Day 2. Roboflow for labeling. Runs locally at
1fps — no hosted inference. EF venue wifi cannot be a hard demo dependency.

**VLM scene reasoner:** Gemini 2.0 Flash. Runs on sampled frames every 1s, adds
scene context to YOLO events. Also runs standalone (VLM-only mode) for production
footage playback — same Detector interface, one config flag switches modes.
Latency budget: max 800ms per Gemini call; beyond that, discard the in-flight
call and emit YOLO-only event. The verifier never blocks on the VLM.

**Agent trace feed:** Pre-scripted TypeScript module that emits structured events
into the same Detector interface as YOLO. Events: `{source: 'agent', step_n,
action_name, action_args, ts}`. The verifier routes by `step_n`, not `source`.
The violation is scripted at step 4 (label fires before packing material).
No actual LLM API call needed during the demo beat — the script replays a
pre-recorded trace. The architecture fully supports live agent calls as a v2 swap.

**Graph visualization:** React Flow with dagre layout. Five nodes, directed graph.
Gray → green on pass (animated edge draw). Red flash + pulsing border on deviation.
Citation card anchored to the violated node as a custom node overlay. ~5-6 hours
to implement. Convex `useQuery` drives node state — no polling, reactive.

**Backend:** Convex. Schema:
- `runs` — `{id, source: 'live_camera'|'playback'|'agent', graph_id, detector, state, current_step, started_by}`
- `graphs` — `{id, sop_doc_id, nodes: [{step_n, expected_action, citation_ref}], compiled_at}`
- `detections` — `{run_id, frame_ts, objects, action_inferred, source, confidence}`
- `citations` — `{run_id, rule_id, source_doc, page, paragraph, text, video_clip?}`
- `incidents` — `{id, json_blob, ingested_at, matched_steps}`
- `reports` — `{run_id, generated_at, citation_chain, recommended_training}`

**New:** `source` field on `detections` (`'camera' | 'playback' | 'agent'`). Left
pane switches automatically based on `source` of the active run — no manual toggle.

**Frontend:** Next.js on Vercel. Four-pane layout:
- Left: live camera feed (or production footage or agent trace log)
- Center: React Flow animated test graph
- Right: citation card + incident match
- Bottom: incident report + run history

**Knowledge layer:** Nia — 3 Core sources (SOP PDF, equipment manual PDF,
incident log JSONL monitored folder). Stretch sources deferred.
Nia citation path: primary (paragraph-level) → fallback (structured JSON).

**NO Tensorlake.** Cut from all scope. If judges ask: "The local compiler is fast
enough at demo scale — Tensorlake is on the roadmap for multi-tenant deployments."

## Verifier State Machine

Same state machine from v1. YOLO + Gemini events and agent trace events enter the
same input queue. The state machine is source-agnostic.

```
              detection event       no detection (5s)
                │                   │
                ▼                   ▼
  ┌──────────┐  start_run   ┌──────────────┐  out-of-order  ┌─────────────┐
  │  IDLE    ├─────────────▶│  AWAITING_N  ├───────────────▶│  DEVIATION  │
  └──────────┘              │              │  detection      └──────┬──────┘
        ▲                   └────┬─────────┘                        │
        │                        │                                  │ flag + cite
        │                        │ step_N detected                  │
        │                        ▼                                  │
        │                   ┌──────────────┐                        │
        │                   │ OBSERVING_N  │                        │
        │                   │ (2s confirm) │                        │
        │                   └────┬─────────┘                        │
        │                        │ confirmed                         │
        │                        ▼                                  │
        │                   STEP_N_DONE → AWAITING_N+1              │
        │                                              │            │
        │  reset                                       │ end_run    │
        │◀─────────────────────────────────────────────┘────────────┘
```

Node state transitions (React Flow):
- `idle → awaiting`: run started
- `awaiting → observing`: step N detected; 2s confirmation window begins
- `observing → done`: confirmed (no contradiction in 2s window)
- `awaiting → deviation`: out-of-order event fires while waiting for step N
- `done → awaiting`: advance to N+1

LOST_SIGNAL: no detection for 5s → LOST_SIGNAL; signal returns within 15s →
resume; lost >15s → auto-reset to IDLE.

## Agent Trace Implementation Detail

The agent trace is a pre-scripted event sequence, not a live LLM call.
Reason: demo reliability. A network hiccup or API rate limit cannot break the story.

`agent-trace-player.ts` event sequence:
```typescript
const TRACE = [
  { step: 1, action: 'pick_up_box', ts: 0 },
  { step: 2, action: 'add_product', ts: 3000 },
  // step 3 (add_packing_material) deliberately omitted
  // step 4 fires while verifier is in AWAITING_3 → out-of-order trigger → DEVIATION
  { step: 4, action: 'apply_label', ts: 6000 },
];
// Violation type: out-of-order (same trigger as the human tabletop demo)
```

Agent trace log in the left pane:
```
[00:00] agent.pick_up_box() ✓
[00:03] agent.add_product() ✓
[00:06] agent.apply_label() ✗ — expected add_packing_material first
```

## Citation Provenance

**Cut:** image region (bbox) citations — complex, marginal demo value.

**Keep:** text paragraph citations (Nia primary → structured JSON fallback).

**Keep as stretch:** video clip citations — if Nia returns `{start_s, end_s,
thumbnail}` by Day 4, surface the clip inline. Omit cleanly if not ready.

The "not just RAG" story:
1. Multi-source cross-query at violation time (SOP + manual + incident log)
2. Live continuous monitoring and ingest (Nia)
3. Citation anchored to specific paragraph + page (not document-level)
4. Prior incident semantic match ("this looks like incident #23")

## Nia Integration

Nia is exercised for:
- **Continuous-monitor ingest** of the live-incident folder (load-bearing for beat #3)
- **Multi-source query** at verification time — pulls across SOP + manual + incident log
- **Cross-source citation chains:** rule violated → manual section → similar prior incident
- **Semantic similarity matching** for prior incident lookup

Citation provenance fallback (Day 1 spike determines which path applies):
- Pre-process SOP PDF into structured JSON: `{sections: [{id, page, paragraph, text}]}`
- If Nia paragraph retrieval works → Nia is primary
- If Nia is document-level only → structured JSON for citation text, Nia owns everything else; document in `NIA_IMPROVEMENTS.md`

Live-ingest deterministic hardening (the wow beat cannot fail):
- Pre-stage incident JSON in a separate folder; "drop" = keypress macro copies it
- Cache the embedding for that file in advance (dry run during dress rehearsal)
- Convex update bound to a specific `incidents.added` event, not a polling loop
- 10-second "Nia is ingesting..." spinner provides cover even if actual work is faster
- **Hard fallback:** hidden hotkey injects new test-graph node directly via Convex mutation

## Success Criteria

1. Test graph compiles from SOP PDF in <30 seconds.
2. YOLO detects all 5 objects correctly under venue lighting.
3. Skipped step → red node flash + Nia citation visible to judges within 1s.
4. React Flow node graph animates smoothly (no jank, no flicker).
5. Production footage plays through same pipeline, surfaces citation at scripted timestamp.
6. Live-ingest beat: new incident → new graph node within 10 seconds.
7. Agent trace beat: deliberate skip → DEVIATION + Nia citation. Judges say "whoa."
8. Convex propagates all state without page reload throughout.
9. `NIA_IMPROVEMENTS.md` delivered as submission deliverable.
10. Full demo runs offline (Day 6 wifi-off rehearsal passes).

Non-goals:
- General industrial CV (only 5 specific objects need to work)
- Multi-camera support
- Authentication / multi-tenant
- Hyperspell, World Labs, Aside, Reacher
- Tensorlake (cut)
- Image region bbox citations (cut)
