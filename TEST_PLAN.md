## Frameworks

- **Unit:** Vitest
- **E2E:** Playwright
- **Eval:** simple input/output JSON comparison (no framework needed)

## Affected Routes / Pages

- `/` — main demo dashboard (3-pane layout: camera | test graph | citation)
- `/runs/:id` — historical run replay (single-page detail)
- `/sop/:id` — SOP and citations explorer (debug-only, behind hidden URL)

## Key Interactions to Verify

- **Hotkey START** triggers a new Run with correct graph_id and detector
- **Camera frame ingestion** drives detection events into the verifier
- **Step transitions** (correct → green node), **deviation** (wrong order → red flash)
- **Citation card** renders text + video clip (if present) + image region (if present)
- **Live ingest** of new incident JSON updates the test graph in real time
- **Hidden hotkey fallback** for live ingest produces visually identical outcome
- **Source switch** (live camera ↔ playback) creates a new Run, prior Run state stays isolated

## Edge Cases

- **State machine:**
  - Out-of-order detection (step 3 before step 2) → DEVIATION
  - Rapid-fire duplicate detections → debounced
  - Step N detected twice → idempotent, current_step does not double-advance
  - Lost signal for 5+ seconds → LOST_SIGNAL state
  - Signal returns within 15s → restore prior state
  - Signal lost > 15s → auto-reset to IDLE
  - Detection during DEVIATION → ignored until end_run

- **Citation resolver:**
  - Nia returns paragraph-level → use directly
  - Nia returns document-level → fall back to structured JSON
  - Nia times out (>500ms budget) → fall back to JSON
  - rule_id not in cache or JSON → render "Citation lookup failed" with rule_id (do not blank)
  - Multi-modal fields (video_clip, image_region) surface when present, hidden when absent

- **Live ingest watcher:**
  - File added but malformed JSON → log error, do not crash, do not add node
  - Nia ingest fails → hidden hotkey fallback path adds node directly via Convex mutation
  - Multiple files added in rapid succession → process each independently, no race

- **Network resilience:**
  - Nia unreachable → JSON-only citation path
  - Gemini Flash unreachable → skip VLM call, use YOLO-only signal
  - Convex cloud unreachable → fall back to local Convex dev instance
  - Full offline (Day 6 wifi-off rehearsal) → demo runs end-to-end

## Critical Paths (these MUST work end-to-end)

1. **Live tabletop happy path:** START → 5 correct steps → all nodes green → COMPLETED. Acceptance: each step's citation appears within 200ms; final state is COMPLETED; no console errors.

2. **Live tabletop skipped step (the money beat):** START → step 1 correct → skip step 2, do step 3 → DEVIATION → red flash + citation card with verbatim quote + prior incident match shown. Acceptance: red flash within 1s of skip; citation surfaces correct rule (`§2.3, page 2, paragraph 1`); incident card shows matching prior incident.

3. **Production playback with scripted skip:** START playback → VLM detects steps in sequence → at scripted timestamp, skip detected → DEVIATION + citation. Acceptance: scripted skip lands at known timestamp ±2s; citation surfaces; UI does not flicker between live-tabletop and playback graphs.

4. **Live ingest beat:** mid-run, drop new incident JSON into watched folder → spinner shows "Nia ingesting..." → within 10s, test graph adds new check node → dashboard updates without page reload. Acceptance: graph node appears within 10s online; if Nia path stalls, hidden hotkey fallback fires within 1s of operator press and produces visually identical outcome.

5. **Source switch mid-pitch:** while live tabletop run is in DEVIATION state, demo ops triggers playback run via hotkey → new Run created → playback graph loads → previous Run remains visible in run history. Acceptance: no state bleed between runs; playback graph nodes start from gray, not inheriting tabletop's state.

## What Not to Test (intentional)

- YOLO detection accuracy: validated via Roboflow's held-out validation set during training, not at runtime. Roboflow's eval is the test.
- Convex schema correctness: TypeScript types are the test.
- Visual regressions on the dashboard: rehearsal is the test (3 timed dress rehearsals on Days 4, 5, 6).
- Multi-tenant / auth flows: deferred per design doc non-goals.
